The Key Promoter X helps you to learn essential shortcuts while you work. When you use the mouse on a button inside the IDE, the Key Promoter X shows you the keyboard shortcut that you should have used instead.
This makes it easier to replace repetitive mouse actions with keyboard shortcuts and gradually move toward a faster, mouse-free workflow. The Key Promoter X tool window shows the mouse actions you use most often and the shortcuts you can use instead. For actions that do not yet have a shortcut, Key Promoter X can prompt you to create one directly.
